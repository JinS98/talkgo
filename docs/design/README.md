# Talkgo UI/UX 검토 시안

[상호작용 시안](talkgo-ui-preview.html)에서 Chat·Board·Calendar 탭, 워크스페이스 메뉴, 채팅 메시지의 **업무로 변환** 모달을 확인할 수 있다. 초기 Taskgo 업무용 화면을 만든 당시의 시안과 이미지로, 파일명은 새 브랜드에 맞췄지만 캡처 안의 구 로고는 기록으로 남아 있다. 현재 앱은 채팅·업무 보드·캘린더를 하나의 사이드바에서 전환한다. 모임용 UI는 [확장 계획](../11-talkgo-expansion.md)에 따라 추가한다. 실제 기능은 `npm run dev:all`로 실행한 앱에서 확인한다.

## 제안 팔레트

| 역할 | 색상 |
|---|---|
| 페이지 배경 | `#F5F6F9` |
| 카드·메인 화면 | `#FFFFFF` |
| 기본 텍스트 | `#202838` |
| 보조 텍스트 | `#677284` |
| 경계선 | `#E4E8EF` |
| 주요 액션 | `#5849C8` |
| 선택 배경 | `#F0EDFF` |
| 완료·진행 보조색 | `#187765` |

초기 시안은 사이드바 264px, 상단 헤더 65px, 뷰 탭 51px의 2단 구조를 기준으로 했다. 현재 앱은 데스크톱에서 280px 단일 사이드바와 상단 헤더를 사용한다. 카드 모서리는 9~15px, 주요 여백은 8·16·24·32px 계열로 맞췄다. 실제 앱의 FullCalendar 월간 화면은 업무 기간·검수 기한·회의를 구분한다. 확정 업무는 단색, 요청 대기는 점선 테두리로 표시하며 팀 전체·내 담당·내가 요청한 검수 필요 업무를 필터링한다. 기존 사용 요청에 따라 실제 앱에서는 내 채팅 메시지를 오른쪽에 배치한다.
