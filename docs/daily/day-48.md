# 48일차 — 업무량·충돌 표시

- 이전: [47일차](day-47.md) / 다음: [49일차](day-49.md)
- 상태: 계획 (35일차 이후 추가 개발, 1세션 약 3~4시간)
- 근거: [현재 코드와 Talkgo 기획 차이](../11-talkgo-expansion.md)

## 작업

- 보드·캘린더에 미확정 요청과 담당자의 기한 충돌 경고 추가.
- 기존 업무용 동작·데이터 접근 범위를 확인하며 해당 기능의 서버 검증과 화면 상태를 함께 갱신한다.

## 완료 기준

- 경고는 권한 범위의 정보만 쓰며 기존 업무 상태 전이를 유지.
- 관련 권한·오류·재시도 경로를 검증하고 결과를 이 문서에 기록한다.
