## 작업

- 참석자 출발역/지역·교통수단 입력과 비공개 기본값·당일 수정.
- 기존 업무용 동작·데이터 접근 범위를 확인하며 해당 기능의 서버 검증과 화면 상태를 함께 갱신한다.

- 다른 멤버는 원본 위치를 읽지 못하고 추천에 필요한 값만 사용.
