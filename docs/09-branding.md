# Talkgo 브랜드 가이드

- **서비스명:** Talkgo (톡고, 가칭)
- **로고:** 말풍선·대화선과 완료 체크를 결합한 심벌 + `talkgo` 워드마크. 원본은 [`talkgo-logo.svg`](../apps/web/public/talkgo-logo.svg), 파비콘은 [`favicon.svg`](../apps/web/public/favicon.svg).
- **슬로건:** 대화가 일정이 되다. 일할 때도, 만날 때도.
- **앱 색상:** 밝은 페이지 배경 `#F5F6F9`, 흰색 화면 `#FFFFFF`, 기본 글자 `#202838`, 보조 글자 `#677284`, 경계선 `#E4E8EF`.
- **주요 액션:** 인디고 `#5849C8`, 선택 배경 `#F0EDFF`, 완료·진행 보조색 `#187765`.
- **의미:** 말풍선은 대화, 체크는 합의된 업무·약속의 확정을 뜻한다.
- **앱 내 적용:** 브라우저 제목·메타 설명·파비콘·로그인·사이드바에 Talkgo를 사용한다. [기존 UI 시안](design/README.md)의 화면 구성과 글자·여백 규칙은 새 서비스 화면에 맞춰 확장한다.
- **참고:** 상표·도메인 중복 검토 전의 브랜드 초안이다.
